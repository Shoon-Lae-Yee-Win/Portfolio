## How I approach development

1. Clarify the business goal and the user workflow.
2. Break the requirement into small, testable features.
3. Design data relationships, validation rules, and access permissions.
4. Implement reusable backend and frontend components.
5. Test normal cases, validation errors, permissions, and edge cases.
6. Review feedback, fix defects, and document important decisions.
